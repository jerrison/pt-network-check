# In-network PT clinics — East Bay, CA

A single static page listing physical therapy clinics confirmed in-network and accepting new patients under a Blue Shield of California PPO plan, checked via the member "Find a Doctor" directory on October 7, 2026.

**Live site:** https://jerrison.github.io/pt-network-check/

No personal/account information is included — just clinic names, public business addresses, phone numbers, and public ratings.
